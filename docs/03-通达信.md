# 03 通达信热门股票榜单取法

通达信（TDX）全网人气榜 / 热门股票榜，聚合页「五合热榜」与「八一热榜」均内嵌此页。

## 入口

页面（参数已从聚合页源码解析）：

```
https://pul.tdx.com.cn/site/app/gzhbd/tdx-topsearch/page-main.html?tdxId=R2203152117524424893WZV&advId=17&fromCh=2
```

## 数据接口（源码验证）

```
https://pul.tdx.com.cn/TQLEX?Entry=JNLPSE.hotStockList
```

## 请求方式

- 页面 URL 为聚合页 iframe 直嵌地址（含 `tdxId` / `advId` / `fromCh` 参数，参数可能随渠道变化）。
- 榜单数据经 `TQLEX?Entry=JNLPSE.hotStockList` 接口下发；可抓包确认请求头与参数后直连。

## 返回内容

热门股票列表（代码、名称、排名等）；聚合页中通达信列采样**前 100**。

## 注意事项

- `tdxId` 等参数可能与设备/渠道绑定，直连前先抓包核对。
- 接口限流策略未公开，建议低频抓取。

## 验证状态

✅ 页面 URL 与 `TQLEX?Entry=JNLPSE.hotStockList` 接口 URL 均从聚合页源码解析确认；接口直连未单独实测。
