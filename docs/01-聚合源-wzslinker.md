# 01 WzSLinker 聚合源（首选入口）

网页股软联动助手，提供多平台热榜聚合页，是 `stock-hots` 的**首选数据源**：一次抓取即可拿到 8 个平台的排名、综合名次、热度与行情/资金/题材列。

## 入口

| 页面 | URL |
|------|-----|
| 导航首页 | `http://wzslinker.top/?_wv=20261005144523` |
| 工具目录 | `http://wzslinker.top/companys/tools.html`（含「五合热榜」「八一热榜」入口） |
| **八合一热榜聚合页（数据本体）** | `http://wzslinker.top/companys/情绪为王-01八一热榜.html?_wv=20261005144523` |

聚合页标题：「致敬八一 热榜综合…东财·同花顺·开盘啦·通达信·雪球·财联社·淘股吧·大智慧」，聚合 8 平台。

## 页面结构

- 聚合页为前端渲染的大表，核心数据在 `table tbody tr` 行内；每行 tab 分隔全字段：
  `代码 名称 最新价 涨幅 东财 同花顺 开盘啦 通达信 雪球 财联社 淘股吧 大智慧 热度 综合 主力净额 主力% 超大单 超大% 换手% 成交额 流通值 市盈率 [板块 涨停原因]`
- 平台列中 `🥇1 / 🥈2 / 🥉3` 表示该平台榜单前三（解析时需去除非数字字符）。
- 页面标注更新时刻（如「更新: 20:58:41」），抓取时记录该快照时间。

## 读取方式（已实测可用）

1. 浏览器导航到聚合页，等待表格渲染完成。
2. 读 `table tbody tr` 全部行（单次批量上限 200 行；无 offset 参数，需一次读完）。
3. 按上表列序切分字段；平台列做「奖牌」清理后取排名数字；`—` 记缺榜。
4. 综合前十 = 按 `综合` 列排序取前 10；各平台 TOP10 = 按对应平台列排序取前 10。

## 行情代理

聚合页按批次补齐行情，代理接口（从页面源码验证）：

```
http://wzslinker.top/companys/api-proxy.php?type=eastmoney&secids=...
```

`secids` 传股票 id 列表（如 `1.000678`、`0.000002`），分批请求，用于补齐最新价 / 主力资金 / 换手 / 成交额 / 流通值 / 市盈率。

## 已验证限制

- 页面「导出」按钮走页面内逻辑，**不触发浏览器下载**（实测 `wait_for_download` 超时），须直接读 DOM。
- 页面为 JS 渲染：`urllib`/`curl` 直抓源码拿不到表格数据，需浏览器环境（或抓包其数据接口后直连）。
- 聚合页快照与各平台官方榜单可能存在分钟级延迟，以页面标注更新时间为准。

## 验证状态

✅ 2026-10-06 实测：八合一聚合页完整读出 243 只股票、8 平台各自排名、综合名次与行情列；综合前十与 6 个平台 TOP10 独立复算一致。
