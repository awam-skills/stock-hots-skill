# 10-程序化取数（fetch_top10.py）

纯 HTTP 程序化获取「8 平台榜单 + 综合前十 + 简要 JSON」，供定时任务 / 自动化调用，不依赖浏览器。

## 位置与运行

```powershell
python scripts\fetch_top10.py                  # 人类可读：打印综合前十（末尾上报不可用平台）
python scripts\fetch_top10.py --json           # stdout 输出简要 JSON
python scripts\fetch_top10.py --json out.json  # 写入 out.json（UTF-8）
python scripts\fetch_top10.py --top 20         # 综合取前 20（默认 10）
python scripts\fetch_top10.py --check          # 失效自检：逐平台探测 + 聚合页探活，失效 exit 1
python scripts\fetch_top10.py --config my.json # 指定数据源配置（默认：仓库根 sources.json，缺省用内置默认）
```

仅用 Python 标准库（urllib/json），无第三方依赖；Windows PowerShell 5.1 直接运行即可。

## 数据源配置（sources.json，可缺省）

仓库根 `sources.json` 集中管理数据源，脚本启动时加载（`load_sources_config`）：

```json
{
  "aggregator_page": "http://wzslinker.top/companys/情绪为王-01八一热榜.html",
  "urls": { "em": "https://...", "cls": "http://wzslinker.top/..." },
  "disabled": ["xq"]
}
```

- `urls`：覆盖内置接口地址（key 同下表 8 平台；未知 key 告警忽略）；
- `disabled`：禁用平台（不请求、不进综合、`platform_status` 记 `disabled`）；
- `aggregator_page`：聚合页兜底入口（`--check` 探活用；`fetch_hot_rank.py` 同样读取）；
- 配置缺省、缺键或解析失败时回落内置默认（stderr 告警不中断），零配置可用；
- 接口失效时优先改此文件（换地址 / 临时禁用），改完 `--check` 验证，不动脚本。

## 数据源（8 平台榜单接口，浏览器抓包确认）

| 平台 | key | 接口 | 采样深度 |
|------|-----|------|---------|
| 东方财富 | em | `POST https://emappdata.eastmoney.com/stockrank/getAllCurrentList` | 100 |
| 同花顺 | ths | `GET https://eq.10jqka.com.cn/open/api/hot_list/v1/hot_stock/a/hour/data.txt?_=` | 100 |
| 开盘啦 | kpl | `GET http://wzslinker.top/companys/api-proxy.php?type=longhuvip&endpoint=get_hot_phb` | 50 |
| 通达信 | tdx | `GET http://wzslinker.top/companys/api-proxy.php?type=tdx` | 100 |
| 雪球 | xq | `GET http://wzslinker.top/companys/api-proxy.php?type=xueqiu&size=100&_type=10&_=` | 100 |
| 财联社 | cls | `GET http://wzslinker.top/companys/api-proxy.php?type=cls_hot_stock` | 30 |
| 淘股吧 | tgb | `GET http://wzslinker.top/companys/api-proxy.php?type=tgb_notice&_=` | 50 |
| 大智慧 | dzh | `GET https://imsearch.dzh.com.cn/stock/top?size=100&type=0&time=h&_=` | 100 |

要点：

- **东财**接口为 POST（body `{"pageNo":1,"pageSize":100}`，空 body 仅回 10 行——2026-10-08 `--check` 发现并修正），返回 `data:[{sc, rk, ...}]`，`rk` 即人气名次，`sc` 为 `SH/SZ+代码`。
- **同花顺**必须带 `/open/` 前缀（`/api/...` 路径 404）；`data.stock_list[].order` 即名次。
- **开盘啦** `List` 每项为 `[code, name, pct, ?, rank, 0, 0]`，**排名取第 5 列（idx=4）**（第 4 列为涨幅榜名次，勿混用）。
- **通达信**为嵌套数组，首行 `[0,"",100,...]` 为总数行、第二行为表头（`sec_code/stock_name/chg/now_price/ranking`），数据行取 `ranking` 列。
- **雪球 / 财联社**：`data.items[]` / `data[]` 数组顺序即名次。
- **淘股吧** `dto[].ranking` 即名次。
- **大智慧** `result:[{SH688185:1140.6}, ...]` 顺序即名次（值为热度分，仅作参考）。
- WzSLinker 代理接口（tdx/kpl/xq/cls/tgb）无需 Cookie，代理端已代抓；东财 / 同花顺 / 大智慧为官方直连。

## 返回 JSON 结构（--json）

```json
{
  "source": "wzslinker-8-platform-apis",
  "config": "sources.json",
  "snapshot_time": "2026-10-06T21:55:38+08:00",
  "algorithm": "avg-rank (mean of present platform ranks; more platforms first)",
  "depths": {"em": 100, "ths": 100, "kpl": 50, "tdx": 100, "xq": 100, "cls": 30, "tgb": 50, "dzh": 100},
  "platform_status": {"em": "ok", "xq": "disabled", "cls": "fail: HTTP 403", "kpl": "empty"},
  "ok_platforms": ["em", "ths", "tdx", "tgb", "dzh"],
  "top10": [
    {
      "rank": 1, "code": "600825", "name": "新华传媒",
      "avg_rank": 7.0, "platform_count": 5,
      "price": "10.35", "pct": 9.99,
      "platforms": {"em": null, "ths": 6, "kpl": 3, "tdx": 2, "xq": null, "cls": 7, "tgb": null, "dzh": 17},
      "best_platform": ["通达信"]
    }
  ],
  "platform_top": {
    "em": {"label": "东财", "top": [{"rank": 1, "code": "603127", "name": "昭衍新药"}, ...]},
    ...
  }
}
```

- `platform_status` / `ok_platforms` / `config`：各平台取数状态（`ok` / `disabled` / `empty` / `fail: <原因>`）、可用平台列表、生效的配置来源——失败平台明确上报，不静默吞错。
- `top10[]`：综合前十，按 `rank` 升序；`platforms` 为该股 8 平台名次（未上榜 `null`）；`best_platform` 名次最佳平台；`price/pct` 取自榜单自带行情（通达信 / 财联社 / 开盘啦），个别新股涨幅为真实值（如 N 股首日 +206%）。
- `platform_top`：8 平台各自 TOP10（东财接口不含名称，已从其它平台回填）。

## 综合口径（与聚合页名次的差异说明）

聚合页「综合」列是页面私有加权算法（含涨停 / 资金 / 题材因子，无法从接口复现）；本脚本使用可复现的公开口径：

> **候选须在 ≥3 个平台上榜；得分 = 上榜平台名次平均值（越小越热）；同分时上榜平台数多者优先。**

因此脚本综合前十与聚合页展示名次存在序位差异是正常现象（例如 2026-10-06 21:55 脚本综合第 1 为新华传媒，聚合页 21:50 综合第 1 为襄阳轴承，两榜前 10 重合约 7 只）。如需完全对齐聚合页名次，请走浏览器读聚合页 DOM 的路径（docs/01）。

## 失败处理（降级链 + 明确上报）

- 单平台接口失败：不中断整体取数，综合计算自动跳过该平台；状态记入 `platform_status`（`fail: <原因>` / `empty`），人类可读输出末尾打印「不可用平台：…（原因）」，JSON 中 `platform_top.<key>` 为空数组。
- 禁用平台（`sources.json` 的 `disabled`）：不请求、不进综合，状态记 `disabled`，不计入失败。
- 可用平台不足 3 个：综合口径（≥3 平台上榜）无候选，打印警告；此时改走聚合页路径（docs/01）或检查 `sources.json`。
- 失效自检：`--check` 逐平台探测（请求 + 解析行数）并探活聚合页，任一启用平台 FAIL/EMPTY 或聚合页不可达即 exit 1，供定时任务 / CI 主动发现接口时效问题。
