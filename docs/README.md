## 时效性自检

接口随时可能变更（限流、参数失效、结构变动）。定期或每次关键任务前运行：

```powershell
python ../scripts/fetch_top10.py --check   # 逐平台探测 + 聚合页探活；存在失效源时 exit 1
```

- 判失效：启用平台请求失败（FAIL）或解析为空（EMPTY，疑似结构变动）、聚合页不可达；配置中 `disabled` 的平台不计；
- 发现失效源时：优先改仓库根 `sources.json`（换接口地址 / 临时禁用平台），再跑 `--check` 验证；接口取法细节见对应平台文档；
- 日常取数也会如实上报：人类可读输出末尾打印「不可用平台：…（原因）」，JSON 含 `platform_status` / `ok_platforms`。

## 推荐流程

1. **程序化（首选）**：运行 `../scripts/fetch_top10.py`（纯 HTTP 请求 8 平台接口），输出综合前十 + 简要 JSON。适合定时任务、自动化，无需浏览器。见 [10-程序化取数.md](10-程序化取数.md)。
2. **完整榜单（含资金/题材）**：抓取 WzSLinker 八合一聚合页（见 [01-聚合源-wzslinker.md](01-聚合源-wzslinker.md)），一次拿到 8 平台排名 + 综合名次 + 行情/资金/题材列（浏览器渲染读 DOM）。
3. **单平台兜底**：聚合页不可用时，按各平台文档直连其页面或接口。

## 数据口径

- **综合排名（聚合页）**：聚合页按 8 平台排名加权得出，越小越靠前；`热度` 为聚合加权分，越小越热。
- **综合前十（脚本）**：候选须≥3 个平台上榜；得分=上榜平台名次平均值（越小越热），同分时上榜平台数多者优先。与聚合页展示名次可能存在差异（口径不同），详见 [10-程序化取数.md](10-程序化取数.md)。
- **平台排名**：各平台榜单内的名次（1 = 榜首）。
- **缺榜**：股票未进入该平台采样深度（如财联社前 30、淘股吧前 50）时记 `—`。
- **行情**：最新价 / 涨幅优先取自通达信、财联社、开盘啦榜单自带字段；其余按需经 WzSLinker 行情代理（`type=eastmoney&secids=...`）补齐。
