## 推荐流程

1. **首选**：直接抓取 WzSLinker 八合一聚合页（见 [01-聚合源-wzslinker.md](01-聚合源-wzslinker.md)），一次拿到 8 平台排名 + 综合名次 + 行情/资金/题材列。
2. **单平台兜底**：聚合页不可用时，按各平台文档直连其页面或接口（同花顺 / 通达信 / 东方财富 / 财联社有明确入口，其余平台直连未经受验证，需现场调试）。

## 数据口径

- **综合排名**：聚合页按 8 平台排名加权得出，越小越靠前；`热度` 为聚合加权分，越小越热。
- **平台排名**：各平台榜单内的名次（1 = 榜首）。
- **缺榜**：股票未进入该平台采样深度（如财联社前 30、淘股吧前 50）时记 `—`。
- **行情**：最新价 / 涨幅 / 主力净额 / 换手 / 成交额 / 流通值 / 市盈率，经 WzSLinker 行情代理分批补齐。
