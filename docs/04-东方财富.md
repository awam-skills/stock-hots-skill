# 04 东方财富热门股票榜单取法

东方财富（eastmoney）人气榜 / 热股榜，聚合页「五合热榜」与「八一热榜」均内嵌此页。

## 入口

```
https://vipmoney.eastmoney.com/collect/stockranking/pages/ranking9_3/list.html
```

## 请求方式

- **页面**：以上 URL 浏览器直接打开（榜单页，SPA 渲染）。
- **行情代理**：聚合页经 WzSLinker 代理补齐东财行情：

  ```
  http://wzslinker.top/companys/api-proxy.php?type=eastmoney&secids=...
  ```

  `secids` 形如 `1.000678`（沪）/ `0.000002`（深），分批传参。

## 返回内容

榜单行（代码、名称、排名等）+ 行情字段（最新价、主力净额、换手、成交额、流通值、市盈率）；聚合页中东财列采样**前 100**。

## 注意事项

- 东财榜单接口较多（人气榜/涨幅榜/资金榜分属不同接口），本技能以聚合页内嵌的榜单页为准。
- 高频请求有风控，建议走聚合页或控制频率。

## 验证状态

✅ 榜单页 URL 实际可用（2026-10-06 经聚合页内嵌访问）；行情代理 URL 从聚合页源码解析确认。
