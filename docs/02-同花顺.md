# 02 同花顺热门股票榜单取法

同花顺（10jqka）人气榜 / 热榜页面，聚合页「五合热榜」与「八一热榜」均内嵌此页。

## 入口

```
https://eq.10jqka.com.cn/frontend/thsTopRank/index.html#/
```

## 请求方式

- **页面**：以上 URL 浏览器直接打开（hash 路由，SPA 渲染）。
- **数据**：页面内嵌于 WzSLinker 五合/八一聚合页时，排名已并入聚合表格；如需直连，抓包页面 JS 发起的榜单接口（页面渲染后 DOM 即含榜单行）。

## 返回内容

榜单行：股票代码、名称、人气/热度排名（1 = 榜首）等；聚合页中同花顺列采样**前 100**。

## 注意事项

- 同花顺对高频请求有风控；建议走聚合页或控制频率。
- 页面为前端渲染，静态源码抓取需配合浏览器或抓包。

## 验证状态

✅ 页面 URL 实际可用（2026-10-06 经 WzSLinker 聚合页内嵌访问）；直连接口未单独抓包验证。
