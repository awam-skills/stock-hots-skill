# 06 开盘啦热门股票榜单取法

开盘啦（kaipanla）热门股票榜，当前经 WzSLinker 八合一聚合页转述。

## 入口

- **聚合页转述**（已验证可用）：八合一聚合页中「开盘啦」列，采样**前 50**。
- **直连接口**：未单独验证。

## 请求方式

1. 首选：抓取八合一聚合页，按列序切出「开盘啦」列排名（见 [01-聚合源-wzslinker.md](01-聚合源-wzslinker.md)）。
2. 直连：如需直连开盘啦官方接口，抓包聚合页的 iframe / 网络请求确认其榜单地址与参数（本次未验证，需现场调试）。

## 返回内容

热门股票列表；聚合页中开盘啦列采样前 50，缺榜记 `—`。

## 注意事项

- 开盘啦数据可能嵌入聚合页 iframe 或经代理转发，直连前先确认请求链路。
- 榜单实时性以聚合页标注更新时间为准。
