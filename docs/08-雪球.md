# 08 雪球热门股票榜单取法

雪球（xueqiu）热门股票榜，聚合页「五合热榜」与「八一热榜」均内嵌此页。

## 入口

```
https://xueqiu.com/hot/stock
```

## 请求方式

- **页面**：以上 URL 浏览器直接打开（热门股票页面）。
- **数据**：页面内嵌于 WzSLinker 聚合页时，排名已并入聚合表格；如需直连，抓包雪球前端数据接口（雪球为站内 JSON 接口，需携带 Cookie / 风控头）。

## 返回内容

热门股票列表（代码、名称、排名等）；聚合页中雪球列采样**前 46**。

## 注意事项

- 雪球反爬较强（Cookie 校验、签名），直连难度较高，**建议走聚合页**。
- 榜单实时性以聚合页标注更新时间为准。

## 验证状态

⚠️ 页面 URL 可见（五合/八一聚合页内嵌）；2026-10-06 数据经聚合页读出，直连未验证。
