# 05 财联社热门股票榜单取法

财联社（cls.cn）热门股票榜单接口，聚合页「五合热榜」与「八一热榜」均引用此接口。

## 数据接口

**直连（已失效）**：

```
https://api3.cls.cn/quote/toplist?app=cailianpress&sv=835&os=android
```

**可用路径（WzSLinker 代理，推荐）**：

```
http://wzslinker.top/companys/api-proxy.php?type=cls_hot_stock
```

## 请求方式

- 代理接口 GET 请求即返回 JSON 榜单，无需 Cookie，代理端已代抓（`fetch_top10.py` 即走此路径）。
- 直连接口 2026-10-08 复测返回 HTML 而非 JSON（多个参数变体均同，疑似接口要求 sign 参数或已迁移），暂时放弃直连；失效详情见下方验证状态。

## 返回内容

热门股票列表（代码、名称、排名等）；聚合页中财联社列采样**前 30**。

## 注意事项

- 接口参数可能随版本更新（`sv` 为接口版本号），失效时抓包聚合页网络请求核对新参数。
- 财联社接口建议低频请求。

## 验证状态

- ✅ 代理路径 `type=cls_hot_stock`：脚本实测可用（2026-10-06 验证，2026-10-08 复测 rows=30）。
- ❌ 直连 API URL 从聚合页源码解析确认（app=cailianpress 移动端参数），2026-10-06 曾返回 JSON；2026-10-08 复测返回 HTML 页面（HTTP 200 但非 JSON），多组 `app/sv/os` 参数均同，疑似需 sign 参数或接口已迁移。`scripts/fetch_hot_rank.py` 的直连探活会如实上报该状态。
