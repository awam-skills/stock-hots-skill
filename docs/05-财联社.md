# 05 财联社热门股票榜单取法

财联社（cls.cn）热门股票榜单接口，聚合页「五合热榜」与「八一热榜」均引用此接口。

## 数据接口（源码验证）

```
https://api3.cls.cn/quote/toplist?app=cailianpress&sv=835&os=android
```

## 请求方式

- 以上接口返回 JSON（榜单列表），GET 请求，参数 `app` / `sv` / `os` 已在 URL 内。
- 可直接用脚本请求并解析 JSON（本技能 `scripts/fetch_hot_rank.py` 内置该示例）。

## 返回内容

热门股票列表（代码、名称、排名等）；聚合页中财联社列采样**前 30**。

## 注意事项

- 接口参数可能随版本更新（`sv` 为接口版本号），失效时抓包聚合页网络请求核对新参数。
- 财联社接口相对开放，但建议低频请求。

## 验证状态

✅ API URL 从聚合页源码解析确认（app=cailianpress 移动端参数）；返回结构未单独逐字段验证，以聚合页列为准。
